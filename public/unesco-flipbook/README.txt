Интерактивная версия доклада «Диагностический анализ основных проблем криосферы в Центральной Азии» (ЮНЕСКО, Алматы)
Языки: EN (94 стр.), RU (104 стр.). Кнопка KZ неактивна, потому что казахская версия не предоставлена.

КАК РАЗМЕСТИТЬ НА САЙТЕ
1. Скопируйте папку unesco-flipbook целиком на веб-сервер, например в /reports/unesco/.
2. Откройте https://<ваш-сайт>/reports/unesco/index.html.
   Сервер, база данных и PHP не нужны. Подойдёт любой хостинг, который отдаёт обычные файлы.
3. Чтобы встроить в страницу сайта:
   <iframe src="/reports/unesco/index.html" style="width:100%;height:90vh;border:0" allowfullscreen></iframe>
4. Чтобы сразу открыть русскую версию, добавьте к адресу #ru: index.html#ru

ПРОСМОТР БЕЗ СЕРВЕРА
Откройте index.html двойным щелчком, всё работает офлайн.

СОСТАВ
index.html                   страница листалки
assets/page-flip.browser.js  библиотека перелистывания StPageFlip 2.0.7 (лицензия MIT, assets/LICENSE-page-flip.txt)
assets/fonts.css, fonts/     шрифт Commissioner (SIL Open Font License, assets/fonts/OFL-Commissioner.txt)
en/, ru/                     изображения страниц (JPEG, 150 dpi), загружаются по мере листания

Внешних запросов нет: ни CDN, ни счётчиков, ни сторонних сервисов.

ФУНКЦИИ
Перелистывание (кнопки, стрелки клавиатуры, перетаскивание угла, свайп), оглавление с переходом к разделам,
кликабельное оглавление на страницах документа, внешние ссылки из текста, поиск с подсветкой на странице,
масштаб до 400 % (кнопки +/− или двойной щелчок), переключение языка с переходом в тот же раздел,
на телефоне по одной странице.
