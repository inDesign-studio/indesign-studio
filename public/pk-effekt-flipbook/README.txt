Интерактивная версия корпоративного профиля ТОО «ПК ЭФФЕКТ» (26 стр., RU)

КАК РАЗМЕСТИТЬ НА САЙТЕ
1. Скопируйте папку pk-effekt-flipbook целиком на веб-сервер, например в /profile/.
2. Откройте https://<ваш-сайт>/profile/index.html.
   Сервер, база данных и PHP не нужны: подойдёт любой хостинг, отдающий обычные файлы.
3. Чтобы встроить в страницу сайта:
   <iframe src="/profile/index.html" style="width:100%;height:90vh;border:0" allowfullscreen></iframe>

ПРОСМОТР БЕЗ СЕРВЕРА
Откройте index.html двойным щелчком, всё работает офлайн.

СОСТАВ
index.html                   страница листалки
assets/                      библиотека StPageFlip 2.0.7 (MIT) и шрифт Commissioner (OFL)
ru/                          изображения страниц (JPEG), загружаются по мере листания
data/ru.js                   оглавление и текст для поиска
Внешних запросов нет: ни CDN, ни счётчиков.

ФУНКЦИИ
Перелистывание (кнопки, стрелки, перетаскивание угла, свайп), оглавление, поиск с подсветкой,
масштаб до 400 %, полный экран, на телефоне по одной странице.
